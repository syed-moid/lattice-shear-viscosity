# Presting 1983 Fig. 2 — cubic BaTiO₃ soft mode, $\Omega_0(T)$ and ABSOLUTE $\gamma(T)$

Paper: H. Presting, J. A. Sanjurjo, and H. Vogt, Phys. Rev. B 28, 6097
(1983) [references/PhysRevB.28.6097.pdf; crop references/Presting_Fig2.jpg].

Figure: Fig. 2, single panel. $\Omega_0$ (circles) and damping constant
$\gamma$ (triangles) of the cubic soft mode by hyper-Raman scattering.
NOTE: $\gamma$ here is the ABSOLUTE classical-oscillator FULL damping
constant in $\mathrm{cm}^{-1}$ — unlike VSR Fig. 3's top panel, which
plots the RELATIVE $\gamma/\Omega_0$.

Axis units AS PLOTTED (verified against the figure image 2026-07-24):
T in KELVIN (300-750 K); $\Omega_0$, $\gamma$ in $\mathrm{cm}^{-1}$
(common 0-250 axis). No conversions applied to the raw files.
